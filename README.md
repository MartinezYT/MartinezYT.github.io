# martinezyt.github.io

Portfolio site for Martin Emeka, AI Automation Developer. Plain HTML and CSS, no build step.

## Publish on GitHub Pages

1. Create a public repo named exactly `MartinezYT.github.io`.
2. Upload `index.html`, `README.md` and the `assets/` folder (or push them with git).
3. Open **Settings → Pages**, set Source to "Deploy from a branch", and choose the `main` branch, `/ (root)` folder.
4. After about a minute, the site is live at https://martinezyt.github.io

## Edit

- Projects: search `index.html` for `<article` and `class="ledger"`.
- After deploying Inbox-to-Action on Render, uncomment the "Try the live demo" link.
- To show your email, uncomment the mailto button in the contact section.
